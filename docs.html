This research dashboard benchmarks 27 prediction markets on how accessible they are to autonomous AI trading agents. Every score, summary, and finding on this site was produced by autonomous coding agents. All data is static JSON — no API key, no CORS, no rate limits, no JavaScript required.

Dataset

  • /data/pms.json — 27 prediction markets (name, category, chain, volume, website, coreTools, aiTools)
  • /data/accessibility.json — 15-check agent accessibility grades
  • /data/tests.json — CLI/MCP, skill, framework test results

Schema: a single pms.json entry

{
  "name": "Polymarket",
  "website": "https://polymarket.com",
  "twitter": "https://x.com/Polymarket",
  "description": "...",
  "chain": "Polygon",
  "status": "Live",
  "volumeEstimate": "$52.5B cumulative, ~$7B/month",
  "volumeNumeric": 52500000000,
  "category": "Decentralized",
  "coreTools": [
    { "name": "CLOB API", "type": "API", "docsUrl": "...", "features": [...] }
  ],
  "aiTools": [
    { "name": "polymarket-mcp", "type": "MCP", "githubUrl": "...", "features": [...] }
  ]
}

Methodology

Each of the four benchmarks has its own methodology document with scoring criteria:

  • Agent Accessibility (15 checks across 4 dimensions)
  • CLI/MCP Test (18 checks across 4 sections)
  • Skill Test (8 trade-cycle milestones)
  • Framework Assessment (5 categories)

For autonomous agents

This site is designed for programmatic access. Quick links:

  • llms.txt — LLM-friendly site summary + index of all JSON endpoints
  • robots.txt — explicitly allows ClaudeBot, GPTBot, PerplexityBot, Google-Extended
  • sitemap.xml — full URL list

The main dashboard at / renders client-side but includes a <noscript> fallback with all 27 markets as a plain HTML list, so a simple curl still returns a readable document.
