Can an AI agent discover, read, and understand this PM's website without a browser? 15 checks across 4 dimensions.

Methodology: Automated via curl/fetch (no browser). Each PM's main site and docs subdomain tested separately. Sites behind Cloudflare managed challenges return 403 and fail most checks — browser-using agents (Playwright) can bypass this. Grade based on pass count out of 15.
Discovery (3 checks)
1.1/llms.txtStandard file that helps LLMs understand what the site is and where to find docs. 700+ sites have adopted it.
1.2Markdown negotiationWhen agent sends Accept: text/markdown, server returns clean markdown instead of HTML. Best agent onboarding path.
1.3Structured metadataMeta description or JSON-LD that tells an agent what the PM does, without parsing the full page.
Crawlability (5 checks)
2.1Content without JSCan an agent read the page with a simple fetch? Fails if the HTML body is empty and needs JavaScript to render.
2.2Semantic HTMLUses <nav>, <main>, <article> etc. so agents can understand page structure, not just a wall of <div>s.
2.3Readable URLsMarket URLs like /markets/us-election vs opaque /markets/0x87c2a. Readable slugs let agents understand content from the URL alone.
2.4SitemapXML sitemap helps agents discover all pages without crawling. Lists markets, docs, key content.
2.5Proper 404sUnknown URLs return HTTP 404, not 200 with an empty app shell. Agents need real status codes to navigate.
Documentation (4 checks)
3.1Dev docs existAny developer documentation at all — API guides, SDK references, integration docs.
3.2Docs findableAn agent can find docs from the main site (linked in nav/footer). Fails if docs are only discoverable via Google.
3.3Programmatic surfaceDocs describe APIs, SDKs, or tools that exist — endpoints, methods, or install commands. Not just conceptual protocol docs.
3.4Standard navigationHomepage uses standard <a href> links, not JS-only routing. Agent can follow links without executing JavaScript.
Access (3 checks)
4.1AI crawlers allowedrobots.txt doesn't block ClaudeBot, GPTBot, PerplexityBot etc. Some sites explicitly block all AI crawlers.
4.2No CAPTCHANo Cloudflare challenge, hCaptcha, or reCAPTCHA blocking automated access to public pages.
4.3Bot policy / agent docsSite or docs have explicit bot policy, agent quickstart, or tool integration docs. Concrete — not just "AI" in marketing copy.

Can an AI agent complete a full trade cycle using only a SKILL.md file and wallet credentials? 8 milestones from reading docs through round-trip trading.

Methodology: An AI agent receives only the skill document + wallet credentials and attempts a full trade cycle. The agent reads the skill, then follows its instructions to authenticate, discover markets, trade, and verify. Real trades with ~$1. Results reviewed and verified. Grade based on pass count out of 8.
Skill Formats
•Pure docsReference documentation only. Agent reads API endpoints, code patterns, contract addresses and writes its own code. (e.g., Polymarket)
•SDK guideStructured docs with SDK code templates, GraphQL queries, WebSocket patterns. Agent follows templates. (e.g., Sapience)
•Executable scriptsPre-built scripts the agent runs directly with flags. Closest to a CLI. (e.g., Baozi)
•Navigation hubRouter SKILL.md linking to subskills. Often references existing MCP/CLI tools. (e.g., Context)
•OpenClawStandardized skill manifest for Claude Code, Cursor, OpenClaw framework. (e.g., Rain)
Trade Cycle Milestones (8)
M1Understand skill & authAgent reads skill, identifies capabilities, auth method, SDKs, and API endpoints.
M2AuthenticateFollow skill's auth instructions. Verify with an API call.
M3List marketsFind 3+ active markets with IDs and titles.
M4Market detail + pricesGet outcomes, probabilities, orderbook for a liquid market.
M5Buy order (~$1)Place and confirm a buy order following skill instructions.
M6Verify positionConfirm position exists with correct market and shares.
M7Sell / close positionExit the position. Note if pari-mutuel (no pre-resolution exit).
M8Balance deltaCompare final balance to pre-trade. Delta should be small (spread + fees).

How mature is this agentic framework for building autonomous prediction market agents? 5 categories assessed on a maturity scale.

Methodology: Each framework reviewed by examining source code, documentation, npm/PyPI packages, GitHub activity, and architecture. Rated on a maturity scale (Production / Usable / Experimental / N/A) rather than a numeric score, since frameworks range from full autonomous trading systems to simple plugins.
Assessment Categories
1TypeWhat the framework actually is: autonomous trading bot, forecasting SDK, agent platform, reference architecture, or plugin.
2ArchitectureComponents and data flow — e.g., RAG pipeline → LLM forecaster → on-chain execution.
3StackLanguage, LLM providers, key dependencies and their versions.
4Platform supportWhich prediction markets and chains the framework targets.
5Setup complexityWhat it takes to get an agent running: install, config, API keys, wallet funding.
Maturity Scale
ProductionActively maintained, documented, real agents using it in production
UsableWorks but has gaps — thin docs, limited adoption, or stale dependencies
ExperimentalProof of concept, abandoned, or not actually a framework
N/ADoesn't fit the category (platform feature, not a framework)
Research compiled from official docs, GitHub repos, and direct verification.
